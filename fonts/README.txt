JHAROKHA REGULAR
Version 1.000, November 2026
Designed by Arijit Ghosh

A heavy display typeface. Latin letters built like Mughal architecture:
onion-arch doorways, bud-shaped windows, minaret domes.

IN THE DOWNLOAD
  Jharokha-Regular.ttf     install this one (Windows, macOS, Linux)
  Jharokha-Regular.woff2   for websites (smallest)
  Jharokha-Regular.woff    fallback for older browsers
  specimen.html            open in a browser to try the font
  OFL.txt                  the licence

WHAT IT COVERS (227 glyphs)
  A-Z, a-z, 0-9, punctuation and symbols, ₹ $ € £
  Western, Northern and Central European letters and accents
  (including AE, OE, eszett, eth, thorn, L with stroke, C S Z N carons)
  Letters for Sanskrit and other Indian languages in Latin script
  (a i u with macron, r l n t d s h m with dots, and so on)

HOW TO USE IT
  It is a display face: headlines, posters, logos, packaging, signs.
  It works best at 24 px / 18 pt and larger. Below that the small
  windows in the letters close up.

  On a website:
    @font-face {
      font-family: "Jharokha";
      src: url("Jharokha-Regular.woff2") format("woff2"),
           url("Jharokha-Regular.woff") format("woff");
    }
    h1 { font-family: "Jharokha", sans-serif; }

KNOWN LIMITS
