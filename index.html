Jharokha

A free display typeface in three weights. The letters are Latin, but they are built like Mughal buildings, with arched doorways, bud shaped windows and small domes.

How it works

Built like a building

A jharokha is the stone balcony that hangs off the front of an old haveli or palace. The font takes its parts from buildings like that. Every letter starts as a solid block, and then the arches get cut out of it.

h

Door

n, m, h and r stand on a pointed doorway. Flip it upside down and you get u.

o

Bud

Round letters are blocks with a window in the shape of a lotus bud.

i

Dome

Tall stems end in a small onion dome. The dots and the full stop are domes too.

A

Cusps

Capital A, H and M get scalloped arches, and A has a pointed finial on top.

Family

Three weights

Lighter weights thin the masonry and widen the doorways and windows, so the architecture stays readable even when the type gets small.

Character set

What is in the box

Capitals, lowercase, figures, punctuation, currency signs (₹, $, €, £), European letters and accents, and the dotted letters you need to write Sanskrit in Latin script.

Sanskrit in Latin letters
Rāmāyaṇa Mahābhārata Prāṇāyāma Nirvāṇa Maṇḍala Gaṅgā

Every dot above or below a letter is a tiny dome, same as the dot on the i.

Use it

Download the zip, open it, and install the three .ttf files (Regular, Bold, Black). For a website, load the woff2 files:

@font-face {
  font-family: "Jharokha";
  font-weight: 400;
  src: url("Jharokha-Regular.woff2") format("woff2");
}
@font-face {
  font-family: "Jharokha";
  font-weight: 700;
  src: url("Jharokha-Bold.woff2") format("woff2");
}
@font-face {
  font-family: "Jharokha";
  font-weight: 900;
  src: url("Jharokha-Black.woff2") format("woff2");
}
h1 { font-family: "Jharokha", sans-serif; font-weight: 900; }
  • Black (900) is built for 24 px and up: posters, titles, book covers, packaging and signs.
  • Bold (700) and Regular (400) open up the counters so subheads, buttons and menus stay clear down to 18 px.
